# 対戦仕様

シミュレーションのターン処理を変える前に、この文書を読む。連戦モードでも、ここに書いた順から外れない。画面の並びと操作は `docs/詳細仕様とUI.md`。どの文書から読むかは `docs/スマホアプリ引継ぎ.md`。

1ターンは、次の順で進めて終わる。

1. 交代の処理（交代するときだけ）
2. スペシャルアタックの発動（撃つときだけ）
3. スペシャルアタックによる戦闘不能の判定
4. ノーマルアタックの発動（その技の最終ターンのときだけ、ダメージとゲージチャージ。このターンにスペシャルアタックがあった技は、カウントを最終ターンまで進めてから処理する）
5. ノーマルアタックによる戦闘不能の判定

戦闘不能の判定で倒れたポケモンは場からいなくなる。そのターンの残りは行わず、そこでターンを終える。進行中だったノーマルアタックは、そこで打ち切る。次のポケモンが出るときは仕切り直しで、技のカウントは引き継がない。次のポケモンが技を出すのは、出た次のターンから。

スペシャルアタックを同じターンに両方撃ったときは、攻撃の実数値が高い方から、1発ずつ全部処理する。実数値は、画面に出ていない小数も含める。小数まで含めて同じときは、順番をランダムにする。先の1発で相手が倒れたら、後のスペシャルアタックは撃たない。

シャドウポケモンの処理は、ダメージの増減だけに使う。攻撃1.2倍、防御は1.2で割る、のどちらもダメージ計算の中だけである。実数値を見比べる同時発動の順番チェックには影響しない。

## 初期条件

戦闘の途中から計算するための、0ターン目の状態。自分と相手で別々に持つ。機能を入れている側だけ使う。入れていない側は、HP最大、ゲージ0、攻撃ランク0、防御ランク0から始める。

- HP残量と、すでに受けたダメージは、足すと最大HPになる。片方を変えるともう片方が変わる。どちらも 0 から最大HPまでの整数。
- 初期ゲージは 0 から 100 の整数。選んでいるノーマルアタック1回分のチャージを足す、または引く。ボタンにはそのチャージ量を書く。100を超えない。0を下回らない。
- 攻撃ランクと防御ランクは -4 から 4。最初の技のダメージから、このランクで計算する。
- 交代で出てきたポケモンには、ゲージもランクも引き継がない。出てきたあとはゲージ0、ランク0。

## シールド

シールドは、そのとき受けるスペシャルアタックのダメージを1にする。追加効果は、発動する技ならシールド中でも発動する。ノーマルアタックには使わない。枚数だけ指定したときは、先に飛んでくるスペシャルからその枚数を防ぐ。防ぐ回を指定したときは、その回だけ防ぐ。

最適は、評価が最大になる技とシールドの回を選ぶ。評価が同じなら、残りゲージが多い方を残す。3ターン以上のノーマルアタックは、ゲージが足りてから追加で通す回数を0～2回に限り、相手の技とのずれが一番小さい回数でスペシャルを撃つ。

ゲージ技の最適は自分と相手で別々に決める。候補が2つ以上で、技選択のカスタム順が無い側は、相手の技順・シールド・個体値など今の条件で対戦を試し、評価が最大になる技を1種類に決めて繰り返す。自分はその中で評価が高い方、相手はその条件で自分の評価が低くなる方を選ぶ。条件が変わったら、そのたびに選び直す。片方だけ技選択をカスタムにしても、もう片方の最適はこの探索のままにする。カスタム順がある側は、その順だけを使う。

タイムラインカスタムがある側は、保存した手順（ノーマルアタック、スペシャルアタック、待機）をターン順に実行する。相手が最適のままなら、相手はその手順を条件にして技を選び直す。ダメージ、ゲージ、シールドの規則は変えない。ゲージが足りないスペシャルアタックは、そのターン何もしない。待機は、その側がそのターン技を出さない。ノーマルアタックは、今選んでいる技のターン数だけ続く。ただしそのターンにどちらかのスペシャルアタックがあると、進行中のノーマルアタックはそこで完了し、残りのターンは失われる。次の技は、失ったターンを飛ばして次のターンから始まる。手順が尽きたあとに、まだどちらも倒れていないときは、そこから先を最適で続ける。詳細は「タイムラインカスタム」の節。

## タイムラインカスタム

この節は、タイムラインカスタムで確定している動き。手順の置き方と、スペシャルでノーマルが短くなる規則は、ここを正とする。

カスタムは、ノーマルアタック、スペシャルアタック、待機の手順を、自分と相手で別々に持つ。表示も対戦も、その2本を同じターン番号へ置く。シールドのマスはタイムラインに置かない。枚数はシールドの表で別に選ぶ。

ノーマルアタックは、選んでいる技のターン数だけ続く。手順に短いターン数が書いてあるときは、その長さで終わる。

そのターンにどちらかのスペシャルアタックがあると、進行中のノーマルアタックはそのターンで完了する。ダメージとゲージチャージはそのターンに入れる。余ったターンは行にせず、次の技は次のターンから始まる。スペシャルで倒れた側の、そのターンのノーマルアタックは、ダメージもチャージも無しで取り消す。例1と同じ。

次の2つは、どちらも正しい。

おどろかす（3ターン）とサイコウェーブ（1ターン）。

```
おどろかす  10  サイコウェーブ
            11  サイコウェーブ
            12  イカサマ
おどろかす  13  サイコウェーブ
```

```
おどろかす  10  サイコウェーブ
            11  イカサマ
おどろかす  12  サイコウェーブ
```

後者は、3ターン目を待たずにイカサマを入れたので、12ターン目が消えて1ターン短い。

ボルトチェンジ（4ターン）とつつく（2ターン）。

```
ボルトチェンジ  9  つつく
               10
               11  そらをとぶ
ボルトチェンジ  12  つつく
```

```
ボルトチェンジ  9  そらをとぶ
ボルトチェンジ  10  つつく
```

後者は、4ターン目まで待たずにそらをとぶを入れたので、余ったターンは消える。2ターンと3ターン、3ターンと4ターン、2ターンと4ターンでも、同じ規則で置く。

途中のターンへ技を入れるときも同じで、そのノーマルは入れたターンの直前までで終わり、後ろは捨てる。

手順を、倒れるより先まで書いてあるときは、倒れた時点で対戦を終える。倒れたあとの手順は表に出さない。

手順が尽きたあとに、まだどちらも倒れていないときは、そこから先を最適で続ける。技の選び方、撃つタイミング、シールドの使い方は、カスタムが無い対戦と同じ。0-0で作った手順を2-2で見ると、同じ手順をその枚数で再生し、手順のあとは2-2の最適で続ける。

もう一度タイムラインカスタムを開くと、いま見ている対戦で最適として続いた技も、手順のうしろに入った状態で開く。

片方だけ手順が短いときは、もう片方の最後のターンに追いつくまで、空いている側へ技を足す。ゲージがスペシャルに足りていればスペシャルを置く。足りなければノーマルを置く。ノーマルが複数ターンなら、空きがそのターン数分たまってから1回分を置く。それより短い空きは空白のままにする。

## ダメージとゲージのタイミング

ダメージとゲージチャージは、その技の最終ターンで、そのターンの処理の中で入る。途中のターンでは入らない。

やきつくすは5ターン技なので、ダメージとチャージは5ターン目の処理で入る。3ターン目に相手のノーマルアタックで気絶したら、そのやきつくすのダメージもチャージもなかったことになる。

スペシャルアタックが途中に入ったノーマルアタックは、そのターンを最終ターンとして扱い、ダメージとチャージを処理する。ただし、そのスペシャルアタックで技の使い手が倒れたときは、そのノーマルアタックのダメージとチャージは取り消す。

ゲージの消費は、スペシャルアタックが実際に発動したときに引く。発動前に戦闘不能で撃たなかった技は、ゲージを引かない。

## サードアタック

メガシンカの一部は、選んでいるスペシャルアタック2つとは別に、サードアタックを1つ持つ。基礎威力とゲージ消費は、トレーナーバトルの＋技の値を使う。

威力だけメガレベルで変わる。レベル1は1.0倍、2は1.1倍、3は1.2倍、4は1.3倍。ゲージ消費はそのまま。ダメージ計算には、基礎威力にこの倍率を掛けた値を入れる。

## 例

### 例1. スペシャルのあとに、生きていればノーマルアタック

残りHP1のAが2ターン技のでんきショック、Bが5ターン技のやきつくす。

```
でんきショック    30    やきつくす
                 31
スペシャルアタック 32
```

32ターンでAのスペシャルアタックは発動する。Bが生きていれば、その後にやきつくすのダメージが入り、Aは倒れる。やきつくすは5ターン技だが、途中にスペシャルアタックがあるので最終ターンまで進んだものとしてダメージを出す。

Bがスペシャルアタックで倒れたときは、Bのやきつくすはダメージもチャージも無しで取り消す。AはHP1のまま生き残る。

### 例2. スペシャルの能力変化は、同じターンのノーマルアタックに乗る

```
あわ    11    からてチョップ
        12
        13    インファイト
```

インファイトで防御が下がってから、11ターン目に始まったあわのダメージを計算する。防御が下がった分、あわのダメージは増える。

### 例3. 交代は1ターン使い、ダメージは出てきたポケモンに入る

```
ころがる    5    ひっかく
            6
            7    交代
```

交代は1ターンを使う。出てきたポケモンが技を出すのは、次のターンから。5ターン目に始まったころがるのダメージは、交代元ではなく、出てきたポケモンに入る。

シールドはトレーナー側の残り枚数を引き継ぐ。交代したポケモンのゲージと能力ランクは、新しいポケモンには残らない。

### 例4. 同時スペシャルアタックは攻撃が高い順に1発ずつ

Aの攻撃がBより高い。Aががんせきふうじ、Bがこごえるかぜを同じターンに撃つ。

1. Aの岩石封じが先に発動し、Bの攻撃が下がる。この時点でこごえるかぜはまだ発動していない。
2. ここでBが倒れたら、こごえるかぜは発動しない。
3. Bが生き残ったら、こごえるかぜが発動する。ダメージは、岩石封じで下がった攻撃で計算する。
