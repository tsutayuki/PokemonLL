# 読みやすさ優先の UI 知見

個体値研究を含む PokemonLL 全体の余白と情報の置き方を直すときに参照したメモ。優先順位は **飲み込みやすさ・使いやすさ** が先、**見た目の洗練** はその次。

対象は、作者のサービス 2 つと、利用者の多い公開サービスの画面・公開ガイドライン 10 件。アクロママシーン9637号は公開 URL を特定できなかったため、このプロジェクトで参照してきた「リーグを記号で見せる・個体値はタップで入れる・数字は表にまとめる」という使い方だけを知見に入れている。

## 見本

| サービス | 何を見たか | 使いやすさで残すこと |
| --- | --- | --- |
| [PsychoWave!](https://psychowave.embrabat-report.net/) | 大会参加者管理。説明文、主ボタン、主催者向け導線が縦に分かれている | 最初の画面で「何をする場所か」と「次に押すボタン」が離れて読める。機能を詰めず、1 画面の仕事を 1 つにしている |
| アクロママシーン9637号 | 作者の個体値ツール（公開ページは未確認） | リーグは紋章、個体値は 0–15 のバー、結果は順位・CP・実数値。文章の見出しより、見慣れた記号と数字 |
| [GOV.UK Design System](https://design-system.service.gov.uk/) | 余白・文字・フォームの公開ルール | 本文は 16px 以上、行間は 1.5 前後。関連する要素は近く、別の話題は大きく離す。タップ領域は 44px 前後 |
| [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/) | レイアウトと余白 | 画面端と中身、中身同士に一定の余白を置く。詰め込みより「ひと目で塊が分かる」ことを優先する |
| [Stripe Docs](https://docs.stripe.com/) | ドキュメントとダッシュボード系の間隔 | 見出し・本文・次の操作の間に余白がある。カードの内側も外側も同じくらい空ける |
| [Linear](https://linear.app/) | 業務ツールの密度 | 情報は多いが、行とセクションの間は一定。色は状態（選択・現在）だけに使い、飾りに使わない |
| [Notion](https://www.notion.com/) | 読み物とブロック | 1 行の幅を広げすぎない。ブロックとブロックの間が、中の行間より広い |
| [Duolingo](https://www.duolingo.com/) | 学習アプリ | 主ボタンは大きく、近くに競合するボタンを置かない。今やる操作が 1 つ分かる |
| [GitHub](https://github.com/) | ナビゲーションと一覧 | ナビの項目同士、一覧の行同士に指が入る隙間がある。選択中は背景で示し、文章を増やさない |
| [Spotify](https://open.spotify.com/) | 一覧と再生 | 行の高さに余裕がある。ラベルは短く、詳細は次の階層 |
| [Material Design](https://m3.material.io/) | 8px グリッドとタッチ | 間隔は 4 の倍数で揃える。隣り合うコントロールは 8px より広く取る。タッチ対象は 48px 前後 |
| [PvPoke](https://pvpoke.com/) | 同じ利用者層のバトル計算 | リーグ・ポケモン・表という順は守る。ただし行間とセル内余白が足りないと数字が追えない。表は残し、行だけ高くする |

## ルール

1. **塊の外側を、塊の内側より広くする。** セクションとセクションは 20–24px。カードの内側は 20px 前後。行の中のラベルと数字は 4–8px でよい。
2. **本文は 16px、行間は 1.5 以上。** 表の数字も 13px を下回らない。順位や CP はそれより大きくする。
3. **押す場所は高さ 44px 以上。** リーグ画像、タブ、検索結果、最近使ったポケモンも、画像の外側に余白を足して押せる面積を確保する。
4. **1 画面の主操作は 1 つ。** 個体値研究では「ポケモンを選ぶ」→「個体値」→「リーグの結果」。同じ役割のボタンを文章と画像で二重に置かない。
5. **リーグは紋章だけ。** 画面上のリーグ名は画像の代替テキストに残し、見える文字としては出さない。画像がないカスタムだけ CP と入力欄にする。
6. **選択中は枠と背景。** 色を増やすより、今選んでいる行・タブ・リーグが周囲より一段浮くようにする。
7. **表はスクロールさせ、行は高くする。** 列を減らしてまで詰め込まない。横の数字の間は 6px 以上空ける。
8. **検索は入力の揺れを吸収する。** ひらがな、カタカナ、ローマ字、英語名、図鑑番号。結果行は名前と絵と番号が同じ高さで並ぶ。
9. **端から 16–20px 空ける。** スマホでもヘッダーと本文が画面端に貼り付かない。
10. **飾りは内容の後ろ。** 背景の模様より、カード内の余白の方が読みやすさに効く。

## このリポジトリへの適用

- 個体値研究: ポケモン選択、タブ、個体値バー、リーグ結果、順位表の間隔を広げた。リーグ見出しとリーグ切替は `Image/league/` の画像だけにした。
- ホーム、ブレイク、シミュレーション: カード・2 列レイアウト・リーグ選択・表セルの余白を同じ基準に寄せた。
- 検索: `src/lib/pogo/kanaSearch.ts` でひらがな・カタカナ・ローマ字を図鑑名に合わせる。
